# Repository instructions

1. Read `handoff/README.md` for repository-specific scope, decisions and constraints.
2. Read `service.yaml` for technical metadata and `README.md` for run and verification commands. Consult relevant notes under `docs/`.
3. If working from the Pitaiya Station, follow its institutional handoff and consult context notes relevant to the task. Use the task workflow chosen by the contributor.
4. At the end of each task, review the context. Record lasting repository changes in `docs/`, update `service.yaml` when its facts change, and update the Station when a product or cross-repository change affects its context.
5. Check the current branch and local changes before editing. Follow the contributor's instructions for actions that change Git or GitHub state. For an authorized PR delivery, read the Station's submission guide when available and use the repository's PR template.
